Sticky Routing: Training MoE Models for Memory-Efficient Inference

When a model uses a mixture‑of‑experts (MoE) layer, only a few experts are active for each input token. In practice, the router often changes its choice from one token to the next, which forces the system to move expert weights between slow storage and fast memory on edge devices. This continual swapping erases much of the speed‑up that sparsity promises.
