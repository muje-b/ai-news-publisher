      Opus 5 builds on the same transformer architecture that powered Fable but incorporates several efficiency tweaks. The model’s parameter count remains in the same ballpark, yet Anthropic reports a 15‑20 % reduction in inference cost per token thanks to optimized kernels and a new quantization scheme.       In addition to lower pricing, Opus 5 lifts many of the usage caps that limited Fable. Rate limits have been raised from 5 k requests per minute to 20 k, and the maximum context window has been expanded from 4 k to 8 k tokens. These changes remove barriers for applications that need longer conversations or higher throughput, such as real‑time chatbots and large‑scale data extraction pipelines.

Anthropic provides a migration guide that outlines the few configuration flags that need adjusting, mainly around token budgeting and temperature settings.
