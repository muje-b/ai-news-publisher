New Tool: Prompt-architect

When working with generative models, turning a vague idea into a precise prompt often feels like guesswork. Prompt Architect Pro steps in as a desktop utility that takes raw text or image input, parses it with a local Ollama‑powered language model, and outputs a clean JSON structure ready for AI image generators.

What You Need to Know

The application is written in Python and runs locally, so no external API calls are required. It loads an Ollama LLM (such as Llama 3 or Mistral) installed on the same machine, feeds it the supplied source material, and asks the model to produce a detailed visual description. That description is then reformatted into a JSON object that matches the schema expected by ComfyUI’s prompt node.

Prompt Architect Pro stores every extracted prompt in an embedded SQLite database. From there you can view, edit, tag, or delete entries without leaving the app. The interface also lets you select a VRAM hardware profile—low, medium, or high—so the underlying Ollama model adjusts its context size and token limits to fit your GPU memory.

A companion ComfyUI node reads directly from the same SQLite file. When you drop the node into a workflow, it queries the database for the selected prompt ID and injects the JSON into the sampler, eliminating the need to copy‑paste strings between programs.

Why It Matters

Manually crafting prompts for diffusion models is time‑consuming and error‑prone. By automating the extraction of visual details from existing notes, sketches, or reference photos, the tool reduces the trial‑and‑error cycle and helps maintain consistency across a series of generations.

Because everything runs on your own hardware, you keep full control over data privacy. No prompts or source images leave your machine, which is important for proprietary concepts or client work that cannot be uploaded to third‑party services.

Key Details

  • Python‑based desktop app with a simple Qt/PySide interface.
  • Uses a locally hosted Ollama LLM to generate structured visual descriptions.
  • Outputs JSON prompts compatible with ComfyUI’s native prompt node.
  • Built‑in SQLite database for storage, tagging, and quick retrieval of prompts.
  • Adjustable VRAM profiles (low/medium/high) that tune Ollama’s context length to your GPU.
  • Includes a ComfyUI custom node that reads prompts directly from the database.

What's Next

The roadmap adds support for exporting prompts to other UI front‑ends such as Automatic1111 and InvokeAI, plus a command‑line mode for batch processing folders of images or text files. Future releases may also introduce prompt versioning and diff views to track how edits affect the final output.
